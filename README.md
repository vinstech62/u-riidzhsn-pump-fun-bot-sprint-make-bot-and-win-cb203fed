A paper-trading bot for pump.fun bonding curves. It reads the replay's market events as they arrive — CreateEvent, TradeEvent, CompleteEvent — and decides when to buy, when to sell, and how much to risk, on 10 SOL of paper money. The strategy is momentum with strict entry filters: buy young coins showing sustained buyer flow and a rising price near its window high, stake a small fixed amount per coin, and exit on take-profit, stop-loss, a trailing stop, or an age cap.

## Run it

```sh
node main.ts
```

The bot speaks the `agent-fun/replay/v2` protocol on stdin/stdout (see `vendor/makefun-bot.ts`). It is fully deterministic: no clock, no randomness, no network, no environment reads — the same replay always produces the same orders.
